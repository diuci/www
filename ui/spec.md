# 丢词夺理全站 UI 规范

适用：主站 diuci.com（本仓）、学古诗 k12.diuci.com、连词 lian.diuci.com、汉兜 handle.diuci.com、画甲骨 jiagu.diuci.com、猜谜 zimi.diuci.com。
遗失月冕与丢词大作战是同一套玩法的另两个站，本规范不约束它们，但顶栏与页脚必须能互相跳得顺。

### 0.1 两站的当前状态（2026-10-19 实测）

| 站 | 跨站出口 | 处理 |
|---|---|---|
| 遗失月冕 moon.diuci.com | 大厅里已有八项乐园链接 | ✅ 已同步 |
| 丢词大作战 ink.diuci.com | **页面内无任何跨站链接**（`dist/index.html` 实测 `diuci.com` 零命中） | ⚠️ **待补**：游戏页需要一个出口，否则玩完出不去 |

ink 是全屏游戏页，加导航要照顾游戏体验（不能挡住玩法、不能打断对局），
属于**新增功能而非样式统一**，需单独设计（暂停菜单内放「换个玩法」链接，或主菜单角落一排小字）。

## 0. 这份规范怎么被执行

- `ui/tokens.css` 是设计令牌的正本（本仓）。其余三站各存一份**字节完全一样**的副本。
- `tools/check-ui.mjs` 是闸门：每个仓跑自己那一份（也是字节一样的副本），配一份本站的
  `tools/check-ui.config.json`。闸门自己带坏例子（`--selftest`），坏例子没被抓住就等于没有闸门。
- 六仓的本地链条与 CI 都必须跑这道闸门。改了样式没跑闸门 = 没改。

## 1. 设计令牌

- 颜色、圆角、字体、阴影、圆钮尺寸一律取自 `ui/tokens.css`。
- 本站 CSS **只许引用**这些名字，不许再定义一遍同名令牌；要自己的名字就 `var()` 指过来
  （如 `--c-primary:var(--cinnabar)`）。把 `#c8442e` 这类色值抄到本站文件里 = 埋下改一处漏一处。
- 本站独有的令牌（VitePress 的 `--vp-c-*`、游戏的 `--c-primary/--c-ok/--c-mis`）留在本站文件里，
  但值必须是 `var()` 指向正本，或是正本里没有的新值。
  正本不替各站决定主色：汉兜的主色是靛青、连词的是朱砂，这一层映射归本站；正本只保证颜色本身六站同名同值。
- 圆钮尺寸正本给死：桌面 `--btn-round:38px`，窄屏 `--btn-round-sm:34px`。

## 2. 顶栏（六站同一个形状）

```
牌子（印章 + 站名） | 八项乐园 | 圆钮：先「繁/简」，后明暗
```

- 八项乐园的名字与顺序，六站必须一模一样：**首页 / 学古诗 / 画甲骨 / 连词 / 猜谜 / 汉兜 / 月冕 / 大作战**。
  本站自己那一项留在栏里并标当前页（`aria-current="page"`）。
- 开源仓库不在顶栏出现，只在页脚出现：顶栏是给孩子跳着玩的。
- 两枚圆钮同尺寸（`var(--btn-round)`）、同圆、同描边、同 hover 色（朱砂）。
- 站内工具钮（汉兜的玩法说明 / 战绩 / 设置）摆在牌子后面，不与乐园抢位置。
- **标签是简称，产品名是全称**：「连词」「月冕」「大作战」只出现在顶栏与页脚的乐园位；
  `<title>`、meta description、README 与法律文本里的站名/产品名保持全称（「连词成句」「遗失月冕」
  「《丢词大作战》」）。**版权主体名「丢词大作战」在任何情况下都不得替换成「大作战」** ——
  它是 `check-legal.mjs` 的 `OUR_COPYRIGHT`，也是各仓 LICENSE 的署名。

## 3. 繁简切换

- 位置：顶栏右侧，**明暗圆钮的左边**，同样式，文案是一个字：当前是简体就显示「繁」，当前是繁体就显示「简」。
  `aria-label` 写全（「繁简切换」），`title` 同。
  那一枚写的字用**切过去那一档自己的字形**：繁体侧写「简」（简体字形），不是「簡」。
  六站在同一模式下必须长得一样——连词曾跟着繁体把它写成「簡」，线上复核当场抓到。
- 状态键：主站与学古诗用 `dc-script`，连词用 `lian-locale`，汉兜用 `handle-locale`；值只有 `hans` / `hant`。
- 不许静默择一：词典里没有的词必须显形（连词把 key 摊在页面上；主站的覆盖闸门当场报错）。
- 学古诗的繁简是**换页**：简体页 ↔ `/trad/` 同名页。没有繁体对应的页面（高考默写、家长指南、
  打印版、数据来源、准确性、版权）不摆这枚钮——摆了就是点了没反应。

### 3.1 繁简钮豁免：哪些站可以没有这一枚

内容本身与繁简无关的站（当前：**画甲骨 jiagu**，其内容是古文字与今字对照，不存在简繁两套），
可以在自己的 `tools/check-ui.config.json` 里写：

```json
{ "allowNoLangBtn": true, "allowNoLangBtnReason": "本站内容为古文字，无繁简之分" }
```

规矩：

1. 豁免**只对明暗钮缺失管用**：豁免后仍必须有明暗钮，缺了照样报错。
2. 豁免必须带 `allowNoLangBtnReason`，且**在本仓 README 里记一句**，不许只写配置。
3. 豁免**不许关掉圆钮的尺寸/正圆/位置检查** —— `check-buttons.mjs` 仍要量明暗钮。
4. 每个豁免都要配一个坏例子（`--selftest`）：证明「不摆繁简钮能过」的同时，
   「明暗钮也没有」仍会被抓住。
5. **绝不为了让闸门变绿而删改 R4 规则本身**。规范 §8：空过的检查比没有检查更危险。

### 3.2 逐页豁免：繁简钮只在有繁体对应页时出现

**这是 R4（静态）与 `check-buttons`（真实浏览器测量）之间必须讲清的一条差**：

- `check-ui.mjs` 是**静态**检查：在 `config.nav` 指定的源文件里找类名，源码里有 `dc-lang-btn` 就过。
- `check-buttons.mjs` 是**真实测量**：开浏览器量渲染后的 DOM。

学古诗与猜谜的繁简是**换页**（简体页 ↔ `/trad/` 同名页）。没有繁体对应页的页面
（首页、打印版、数据来源、准确性、版权、高考默写、家长指南）**本来就不该出现这枚钮** ——
本节开头已经写了「摆了就是点了没反应」。

于是「源码里有、首页渲染后没有」是**正确状态**，但 `check-buttons` 会误报。

**处理**：这类站在 `SITES` 第四项写 `{ noLangOnHome: true }`，意思是「首页不要求有繁简钮，
其余页面照常要求」。**豁免只放过首页，不许整站一刀切** —— 否则真有问题的页面就没人量了。

> 实测记录（2026-10-19）：猜谜站的繁简钮由 `ScriptToggle.vue` 的 `v-if="target"` 控制，
> 首页无 `/trad/` 对名页所以不渲染；学古诗同理。两者都不是缺陷，是上面那条规则的直接结果。

## 4. 明暗切换

- 键 `dc-theme`，值 `light` / `dark`；写进 `<html data-theme>`，同时给 `html.dark`（给 UnoCSS / VitePress 的 dark: 变体）。
- 首帧之前定色：每站 `index.html` 里那段脚本先跑，避免暗色用户看到白屏闪。
- `<meta name="theme-color">` 跟着主题走（宣纸 `#f4ede0` / 夜墨 `#17140f`）。

## 5. 内容字号阶梯（学古诗，其余站同精神）

| 内容 | 桌面 | 窄屏 | 打印 |
| --- | --- | --- | --- |
| 诗题 | 1.7rem | 1.7rem | 14pt |
| 正文（要背的那几联） | 1.3rem | 1.08rem | 12pt |
| 全文（整篇在这里） | 1.15rem | 1.02rem | 11pt |
| 小节标题 | 1.08rem | 1.08rem | 12pt |
| 注释 / 译文 / 赏析 | 1.02rem | 1.02rem | 10.5pt |
| 考证说明（出处、收录判断） | 0.9rem | 0.9rem | 9.5pt |
| 元信息（标签、核对状态） | 0.85rem | 0.85rem | 9pt |

- **同一个内容块内只许一档字号**。同一首诗前两句小、后两句大是缺陷：
  生成器必须把每一行自己包进 `<p>`、行与行之间不留空行（markdown-it 只在空行处结束一段原始 HTML，
  不包就前半吃框架默认 16px、后半吃本站 1.3rem）。
- 这条有闸门：静态查生成产物结构，浏览器实测查算出来的字号（`tools/check-typography.mjs`）。


## 6. 页脚（说明类内容只在这里）

```
左：牌子 / 内容从哪来 / 许可与免责      右：八项乐园 + 三个说明页 + 邮箱
```

- 说明类页面只有三个文件，都在学古诗站：**数据来源与版权 `/sources`、内容准确性 `/accuracy`、版权与免责 `/legal`**。
- 这三条在六站页脚都要出现（学古诗站内用相对链接，其余五站链到 `https://k12.diuci.com/…`）。
- 侧栏、顶栏、底部标签栏**不得**出现这三条：一处入口，四种地方摆 = 孩子找不到、大人改不完。

## 7. 侧栏

- 侧栏不得有自己的滚动条：它随页面整体滚动。
  （VitePress 默认 `.VPSidebar` 是 `sticky + max-height + overflow-y:auto`，本站改成随页面滚。）
- 侧栏只放**内容导航**：总览、繁體版、高考默写、打印版、家长指南、三个学段、各册。
- 窄屏侧栏收进「目录」抽屉，另有底部标签栏（六项，与主站同一组）。

## 8. 闸门清单（每条都配坏例子）

| 闸门 | 盯什么 | 在哪跑 |
| --- | --- | --- |
| `tools/check-ui.mjs` | 令牌副本字节一致、不得重复定义令牌、不得写死正本色、顶栏两枚圆钮、繁简钮文案、说明页只在页脚、侧栏不得自己滚、乐园顺序 | 六仓链条 + 六仓 CI |
| `tools/check-typography.mjs` | 正文每行必须是 `<p>`、块内不留空行、正文里不写死字号、CSS 必须显式给字号 | 学古诗链条 + CI |
| `tools/check-typography-browser.mjs` | 真开浏览器逐页量：同一块正文只许一档字号 | 学古诗本地链条（CI 里没有浏览器，不假装跑过） |
| `tools/check-hant.mjs` | 主站每一段文案都有繁体译法、字典不许留死键、繁体侧不许出现只有简体才用的字 | 主站链条 + CI |
| 跨仓令牌比对（本地链条） | 六仓 `tokens.css` 与正本 sha256 相同 | 本地链条 |
| `tools/check-buttons.mjs` | 真开浏览器量六站顶栏：两枚圆钮同尺寸（38 / 34px）、正圆、繁简钮在明暗钮左边 | 主站本地链条（CI 里没有 Chrome，也不写进 CI） |

空过的检查比没有检查更危险：每条闸门都要有坏例子，坏例子必须当场被抓住。
